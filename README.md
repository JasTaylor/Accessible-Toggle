# Accessible Summary Toggle

A small, dependency-free "Show more" toggle for article summaries, built with native DOM APIs.

- **Progressive enhancement:** without JavaScript, the full list is visible.
- **Accessible:** uses `aria-expanded`, `aria-controls`, and the `hidden` attribute so screen readers stay in sync.
- **Themeable:** CSS custom properties with a dark mode default.

Open `index.html` with a local server (for example `npx serve .`) to see the demo.
